TokenForge API Documentation

TokenForge unifies access to the world's leading LLMs—OpenAI, Anthropic, and Google—behind a single, standardized API. Forget managing multiple providers, complex billing, or disjointed integration code. With one tf_sk_ API key and a simple base_url update, you are ready to integrate.

Getting Started

The Only Change You Need

If you are already using the OpenAI SDK, you don't need to rewrite your application. Simply point your client to our gateway, and you’re done.

# Configure your client to use TokenForge
base_url = "https://tokenforge1-production.up.railway.app/v1"
api_key = "tf_sk_YOUR_TOKENFORGE_API_KEY"

Integration Examples

1. Python

from openai import OpenAI

client = OpenAI(
    api_key="tf_sk_YOUR_TOKENFORGE_API_KEY",
    base_url="https://tokenforge1-production.up.railway.app/v1"
)

response = client.chat.completions.create(
    model="claude-3-5-sonnet-20241022",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}]
)

print(response.choices[0].message.content)

2. Node.js

const { OpenAI } = require("openai");

const client = new OpenAI({
  apiKey: "tf_sk_YOUR_TOKENFORGE_API_KEY",
  baseURL: "https://tokenforge1-production.up.railway.app/v1",
});

async function main() {
  const completion = await client.chat.completions.create({
    model: "gemini-2.0-flash",
    messages: [{ role: "user", content: "Hello!" }],
  });
  console.log(completion.choices[0].message.content);
}

main();

3. cURL (Command Line)

curl https://tokenforge1-production.up.railway.app/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tf_sk_YOUR_TOKENFORGE_API_KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "How are you today?"}]
  }'
