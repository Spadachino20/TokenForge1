Quick Start

Get your first API response in under 2 minutes. No complex setup required.

1. Create Account

Sign up and get free starter credits instantly.

2. Generate API Key

Go to Dashboard → API Keys → Create New Key.

3. Change Base URL

Replace https://api.openai.com/v1 with our endpoint.

Example Request

curl https://tokenforge1-production.up.railway.app/v1/chat/completions \
  -H "Authorization: Bearer tf_sk_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello, world!"}]
  }'

Authentication

All API requests require a Bearer token in the Authorization header.

Important: Never expose your API key in client-side code. Use environment variables or a backend proxy.

Header Format

Authorization: Bearer tf_sk_your_key_here

API Key Types

Type Prefix Description
Master Key tf_sk_... Full access to all endpoints. Use for backend services.
Project Key tf_pk_... Limited to specific project. Ideal for client SDKs.

Base URL

https://tokenforge1-production.up.railway.app/v1

Chat Completions

OpenAI-compatible chat completions endpoint. Drop-in replacement.

POST /v1/chat/completions

Send a chat completion request. Supports all OpenAI parameters plus TokenForge-specific options.

Request Body

Parameter Type Required Description
model string Yes Model ID. See available models.
messages array Yes Array of message objects with role and content.
temperature number No 0-2. Default: 1. Controls randomness.
max_tokens integer No Maximum tokens to generate.
stream boolean No Stream response as SSE. Default: false.
project_id string No Track usage under specific project.

Example Response

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1718900000,
  "model": "gpt-4o",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "Hello! How can I help you today?"
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  },
  "tokenforge": {
    "credits_used": 0.042,
    "credits_remaining": 999.958
  }
}

Error Handling

TokenForge uses standard HTTP status codes and returns JSON error responses.

Status Code Description
400 invalid_request Malformed request or missing required parameters.
401 unauthorized Invalid or missing API key.
402 insufficient_credits Not enough credits for this request. Top up.
429 rate_limit Too many requests. Retry after the specified time.
500 provider_error Upstream provider error. Retry recommended.

Error Response Format

{
  "error": {
    "code": "insufficient_credits",
    "message": "You need 5.00 TFC for this request. Current balance: 2.30 TFC.",
    "type": "request_error"
  }
}

SDKs & Libraries

Use any OpenAI-compatible SDK. Just change the base URL.

Python

from openai import OpenAI

client = OpenAI(
    base_url="https://tokenforge1-production.up.railway.app/v1",
    api_key="tf_sk_your_key_here"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)

JavaScript / Node.js

import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://tokenforge1-production.up.railway.app/v1',
  apiKey: 'tf_sk_your_key_here'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});

console.log(response.choices[0].message.content);

Streaming Responses

Set stream: true for Server-Sent Events (SSE) responses.

const stream = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Tell me a story' }],
  stream: true
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
