Quick Start

Get your first API response in under 2 minutes. No complex setup required.

1 Create Account

Sign up, purchase credits, and start calling any model with a single API key.

2 Generate API Key

Go to Dashboard → API Keys → Create New Key.

3 Change Base URL

Replace https://api.openai.com/v1 with our endpoint.

Example Request

curl https://tokenforge1-production.up.railway.app/v1/chat/completions \
  -H "Authorization: Bearer tf_sk_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Hello, world!"}]
  }'

Authentication

All API requests require a Bearer token in the Authorization header.

Important: Never expose your API key in client-side code. Use environment variables or a backend proxy.

Header Format

Authorization: Bearer tf_sk_your_key_here

API Key Types

Type Prefix Description
Master Key tf_sk_... Full access to all endpoints. Use for backend services.

Base URL

https://tokenforge1-production.up.railway.app/v1

Chat Completions

OpenAI-compatible chat completions endpoint. Drop-in replacement.

POST /v1/chat/completions

Send a chat completion request. Supports all OpenAI parameters.

Request Body

Parameter Type Required Description
model string Yes Model ID. See available models.
messages array Yes Array of message objects with role and content.
temperature number No 0-2. Default: 1. Controls randomness.
max_tokens integer No Maximum tokens to generate.
stream boolean No Stream response as SSE. Default: true — pass "stream": false explicitly if you want a single JSON response instead.

Example Response (non-streaming, stream: false)

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1785000000,
  "model": "gpt-5.6-luna",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "Hello! How can I help you today?"
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  }
}

Error Handling

TokenForge uses standard HTTP status codes and returns JSON error responses.

Status Code Description
400 missing_parameters / model_not_available Malformed request or missing required parameters.
401 unauthorized Invalid or missing API key.
402 insufficient_balance Not enough TFC balance for this request. Top up.
429 rate_limit Too many requests — limit is 100 requests/minute per API key. Wait before retrying.
500 provider_error Upstream provider error. Retry recommended.

SDKs & Libraries

Use any OpenAI-compatible SDK — just change the base URL and use your tf_sk_... key. No custom client required.

Python

from openai import OpenAI

client = OpenAI(
    api_key="tf_sk_your_key_here",
    base_url="https://tokenforge1-production.up.railway.app/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello, world!"}]
)
print(response.choices[0].message.content)

Node.js

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "tf_sk_your_key_here",
  baseURL: "https://tokenforge1-production.up.railway.app/v1"
});

const response = await client.chat.completions.create({
  model: "gpt-5.6-luna",
  messages: [{ role: "user", content: "Hello, world!" }]
});
console.log(response.choices[0].message.content);

Credits & Billing

1 TFC = $1.00 USD. Buy as many credits as you need. Minimum purchase: $10 USD (10 TFC). No subscriptions, no commitments — credits are prepaid and deducted per request, and never expire.

Payment is currently accepted only in cryptocurrency stablecoins (USDT / USDC), processed through NOWPayments. No credit cards or bank transfers yet. Every model is billed at raw provider cost plus a fixed, transparent 20% platform fee — see the Pricing page for the exact rate per model.

Your balance auto-blocks new requests the instant it hits $0 — you'll never see a surprise overage bill. You'll also get an email alert at 20% and 10% of your remaining balance so you can top up ahead of time.

Frequently Asked Questions

I sent USDT/USDC but my balance hasn't updated yet — what's wrong?

Credits are added automatically once your transaction gets enough confirmations on-chain, which is typically a few minutes but can take longer depending on network congestion. If it's been over 30 minutes, check your Dashboard billing history first, then reach out with your transaction hash.

I sent funds on the wrong network — did I lose them?

Always double-check the network (e.g. TRC20 vs ERC20) shown on the payment screen before sending — sending USDT/USDC on a network the deposit address doesn't support is the most common way crypto payments get stuck or lost industry-wide. Use exactly the network and address shown at checkout.

What if I send more or less than the invoice amount?

Underpayments are held until you send the remaining balance to the same invoice; overpayments are credited to your TFC balance rather than refunded on-chain (crypto transactions can't be reversed). If a payment looks stuck, check your Dashboard billing history before resending.

Are unused credits refundable?

Credits don't expire, but they aren't refundable once purchased — there is currently no automated refund flow. If something went wrong with a specific charge, contact us through your Dashboard.

Can I get a receipt for accounting or taxes?

Every deposit and charge is itemized in your Dashboard billing history in USD. A downloadable invoice/receipt export is on our roadmap but not available yet — for now, your transaction history plus your on-chain transaction hash cover most bookkeeping needs.

I'm not a company — can I still use TokenForge?

Yes — TokenForge is built for anyone, from hobbyist developers experimenting with a side project to small businesses running production traffic. There's no minimum commitment beyond the $10 top-up, no seat limits, and no sales calls required to get started.

Streaming Responses

Streaming is on by default. Pass "stream": false for a single JSON response, or "stream": true for Server-Sent Events (SSE).
